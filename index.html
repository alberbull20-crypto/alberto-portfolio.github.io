01 /About

A little about my work.

I'm a software developer who works comfortably on both sides of the screen — interfaces people click on, and the databases and logic quietly holding everything up underneath.

On the web I build with JavaScript and React. Below that, I reach for Python and Django for application logic, C++ and object-oriented VB.NET when a project calls for it, and SQLAlchemy, SQLite, or PostgreSQL to model the data properly.
